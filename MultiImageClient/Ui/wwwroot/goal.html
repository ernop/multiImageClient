image generators (one or more)
Every prompt of every turn is rendered by each selected generator. The manager sees them only as source A, B, … (the same letter is the same generator every turn), scores every render, and continues from the one render it chooses. The goal is one best image from any source.

Every turn renders two images: a refine prompt that improves the render the manager chose to continue from, and a fresh prompt that re-attempts the goal from scratch with a new composition and style. With several generators, both prompts render on every one of them (2 × generators images per turn); the manager sees each generator only as a source letter (A, B, …) and scores every render. It picks the exact render the next refine builds on, so the loop can leave a weak composition or a weak source instead of iterating on it. Max turns counts turns, not images.

The manager is not told which generator renders its prompts. No per-endpoint extra text is appended: the manager owns the whole prompt.
